Para aplicar os parâmetros de aceleração do DataLoader, você deve inseri-los diretamente dentro do objeto 
TrainingArguments no seu script (onde você define as configurações do Hugging Face Trainer).
O Hugging Face encapsula nativamente os argumentos do PyTorch DataLoader dentro dessa classe.
Modifique o trecho de criação do training_args na função main para incluir os dois comandos abaixo:
python    training_args = TrainingArguments(
        output_dir=str(out_dir),
        per_device_train_batch_size=args.batch_size,
        per_device_eval_batch_size=args.batch_size,
        gradient_accumulation_steps=args.grad_accum,
        learning_rate=args.learning_rate,
        num_train_epochs=args.epochs,
        logging_steps=20,
        eval_steps=200,
        save_steps=200,
        eval_strategy="steps",
        save_strategy="steps",
        save_total_limit=2,
        gradient_checkpointing=True,
        bf16=torch.cuda.is_available(),
        fp16=False,
        report_to="none",
        seed=args.seed,
        
        # --- ADICIONE ESTAS DUAS LINHAS ABAIXO ---
        dataloader_num_workers=4,       # Usa 4 núcleos do Ryzen 9 para preparar dados
        dataloader_pin_memory=True,     # Cria canal direto de memória RAM -> RTX 5080
    )
Use o código com cuidado.O que essa alteração vai fazer?dataloader_num_workers=4: O padrão do Hugging Face é 0,
 o que significa que o processo principal executa a busca de dados de forma síncrona, travando a GPU a cada lote (batch).
 Definir como 4 delega essa tarefa para subprocessos em paralelo na CPU.
 dataloader_pin_memory=True: Aloca os dados tokenizados em uma região da memória RAM do sistema que não sofre paginação,
  permitindo que a RTX 5080 puxe os dados via barramento PCIe muito mais rápido.
